## 什么是 Hexo

Hexo 是一个基于 Node.js 的静态博客框架，支持 Markdown 写作，主题丰富，部署简单。

## 写作流程

```bash
# 新建文章
hexo new "文章标题"

# 本地预览
hexo server

# 生成并部署
hexo deploy
```
